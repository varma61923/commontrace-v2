# sovereign-airgapped

Install this configuration with `unimem pack install sovereign-airgapped --dest ./deployment` and run its offline reference demo with `unimem pack demo sovereign-airgapped --seed 20261018`.

Configured roadmap features: G12, G14, G19, G21. Defaults and review rules are shipped in the versioned pack manifest. This is a starting configuration; review rules and integrations against the deployment policy before production. The demo executes the configured features through real local library APIs in temporary stores, then reports a separate seeded synthetic outcome comparison. It makes no network calls; simulated attestation and transparent proofs retain their stated limitations. Its estimate is not evidence of field performance or certification.
