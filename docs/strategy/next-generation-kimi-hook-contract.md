# Kimi native hook contract pass

Kimi Code reads lifecycle hooks from the active `config.toml`. Its `[[hooks]]` entries allow only `event`, `matcher`, `command`, and `timeout`; `event` and `command` are required, and timeout is an integer from 1 to 600 seconds. CommonTrace now edits the active file in place, replacing only a marked CommonTrace region while preserving the user's model, provider, and hook settings. Repeated setup leaves one CommonTrace region. It rejects undocumented events, empty commands, malformed or duplicate managed regions, and symlinked targets before writing.

By default, setup resolves the host file from `$KIMI_CODE_HOME/config.toml` or `~/.kimi-code/config.toml` and returns `kimi` as the activation command. `agents.kimi.config_path` can explicitly select another absolute host config path; relative overrides remain bounded to the project root. This avoids using `--config-file` with a hook-only fragment: Kimi's CLI docs state that the flag replaces the default config, which would discard provider/model settings.

The current [Kimi Code Hooks reference](https://www.kimi.ai/help/kimi-code/cli-hooks) defines the entry schema and timeout range. The current [config overrides reference](https://www.kimi.com/code/docs/en/kimi-code-cli/configuration/overrides) says the CLI reads one user-level config and has no project-level config file. The upstream CLI's [archived config overrides reference](https://github.com/MoonshotAI/kimi-cli/blob/main/docs/en/configuration/overrides.md) explicitly says `--config-file` replaces the default file. The local Mem0 Kimi plugin provides a useful competitor example: it merges marked hook entries into the active `~/.kimi-code/config.toml`, preserves user hooks, and tests reinstallation. Hindsight's local Kimi hook comments also call out the strict hook entry schema.

Focused verification: `pytest tests/test_native_hooks.py tests/test_bootstrap_runtime.py` and Ruff passed. Bootstrap tests use temporary home directories, including a `KIMI_CODE_HOME` override and an explicitly configured external config path; they do not touch a real user config. TOML parsing assertions run when `tomllib` or `tomli` is available, preserving the package's Python 3.10 support.
