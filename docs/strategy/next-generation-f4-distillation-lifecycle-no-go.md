# F4 distillation lifecycle audit: no-go

No additional lifecycle patch is justified. `session_learning.learn()` offers up to ten intent-relevant prior lessons to its curator, requires an explicit writer accept/reject decision, and persists accepted proposals as quarantined lessons with case IDs, versions, trace IDs, and update/split relations. It calls `Journal.seal()` only after model calls and grouped persistence complete; exceptions leave the captured work replayable. See [session_learning.py](../../commontrace/session_learning.py#L231) and the failure/retry, rejection, prior-selection, split, and lineage checks in [test_session_learning.py](../../tests/test_session_learning.py#L33).

The procedural-skill route also retains lineage: [`experience_skills.py`](../../commontrace/experience_skills.py#L178) clusters only explicit procedures and outcomes; proposals persist the structural signature, source trace IDs, and source digests ([lines 14–18](../../commontrace/experience_skills.py#L14), [lines 27–60](../../commontrace/experience_skills.py#L27)). Existing integration coverage checks the skill’s retained raw sources and causal promotion gate.

Competitor inspection supports the same boundaries rather than a missing CommonTrace feature. Cognee distinguishes curator failure from an empty proposal, counts writer failures, and advances its session watermark only after publishing or a completed no-op ([distill.py](../../../cognee/cognee/modules/session_distillation/distill.py#L213), [lines 452–530](../../../cognee/cognee/modules/session_distillation/distill.py#L452)). EverOS groups by cluster and hydrates skills’ `source_case_ids` into bounded supporting-case context ([extract_agent_skill.py](../../../EverOS/src/everos/memory/strategies/extract_agent_skill.py#L1)). Graphify queries of CommonTrace, Cognee, and EverOS located these paths; the local Letta graph contains only README nodes and yielded no comparable implementation.

Skill activation quality remains an evidence gate: proposals stay review-only until a paired raw-vs-skill causal comparison passes, so model-backed skill usefulness cannot be established by these deterministic lifecycle tests.
