# Valuation and warranty evidence

`frontier valuation` computes main and pairwise factorial contrasts from a
complete independent Bernoulli inclusion vector per task. Declare probabilities,
propensity floor, fixed family and alpha in advance. Main values average over
other memories' inclusion; pairwise contrasts expose redundancy/complementarity.
The Data Banzhaf connection is a design analogy, not an equivalence claim.

`frontier valuation-certify` reconstructs canonical current-salt assignments,
requires readable integrity and transparency-anchored assignments/outcomes, then
signs and anchors the report. Adaptive/jointly dependent schedules are refused.
`valuation.verify` checks portable authentication using a pinned store verifier;
`require_attested=True` distinguishes canonical evidence from a signed external
report. Authentication alone does not establish the scientific assumptions.

`frontier warranty` takes a canonical bundle, immutable `contract`, `memory`,
`minimum_lift` and `paid_cents`. A credit triggers only when the whole interval is
below the floor. The signed credit ledger is idempotent and caps all credits for
a contract at the amount paid. `hub.value_billing.warranty_line` prepares a
negative billing line; sending money remains an explicit configured operation.

`frontier underwriting` exports signed reliability, incident, configured harm
budget, change-certificate and credit fields. Verify with
`valuation.verify_export`. Empty evidence is shown as empty, not fabricated.
`frontier data-value` ranks bounded episode metadata and intervention segments
by measured memory effect in LeRobot/RECAP-style interchange layouts. Raw media
and model training tensors remain in the robot data plane; this is not a complete
native LeRobot dataset writer or an insurance certification.

Canonical certificates bind the configured experiment salt and content revisions
and require all eligible factorial occasions to be resolved. Signed training
exports use `export_data` (the CLI's `data-value` operation); verify their manifest
and anchor with `verify_export`.
