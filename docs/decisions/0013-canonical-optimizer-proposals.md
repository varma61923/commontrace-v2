# 0013: Optimizer proposals remain hypotheses

G3 stores the proposed edit separately from its claimed validation score.
Content-bound typed units publish their schedules before assignment. Complete
canonical outcomes, fixed trial criteria and the existing promotion certificate
remain necessary for activation; a vendor score cannot authorize it.

A frozen matched-pilot harm gate determines eligibility before the factorial
assignment. Harmful ACE bullets are withdrawn as individual units. The recorded
joint catalog is immutable across retries. The full catalog is validated before
any assignment, and current source/capability admission is checked before egress.
Source digests cover admitted facts, lessons, runtime records and traces rather
than assuming all source classes expose one particular digest field.

GEPA and DSPy adapters independently map pinned serialization fields, checked by
authored fixtures. Their status identifies the verified subset. DSPy runtime LM
configuration is discarded and never deserialized. ACE, Training-Free GRPO and
normalized envelopes remain explicitly format unverified. No third-party code,
SDK or dataset is vendored.

Per-segment frontiers use randomized outcomes, with complete cohorts and fixed
pre-treatment segments. They are exploratory estimates. Promotion still requires
the full canonical certificate. The public pooled fingerprint hashes the edit,
while the local artifact hash also binds base and parent context.

Seeded simulation exercises the actual evaluation path for bias, coverage and
null promotion. Integration tests exercise harmful-bullet withdrawal, positive
certificates, missing outcomes, source changes, scope, leaf capabilities, CLI/MCP
and credential stripping. An isolated mutation replacing the frontier effect with
a claimed validation score is detected by the zero-effect regression.
