# 0015: Separate agreement labels and fixed personalization cohorts

Status: accepted.

Keep canonical primary outcome bytes unchanged. Source-link deletable secondary
metric payloads and commit them in the transparency history before the primary
outcome. Freeze actual query texts, catalog members, cyclic matched query order,
horizon and margins before assignments; authenticate the complete first cohort.

Use three simultaneous finite-horizon Hoeffding intervals with a known baseline
and exact propensities. A flattering flag requires positive agreement and outcome/
accuracy equivalence within a stated practical-benefit margin. Non-significance
does not establish equivalence. Down-weight matching current source content as an
allocation heuristic; do not turn a positive bundle effect into individual factual
permission. Newer cohorts take precedence over older applied evidence.

Factual action classes require a current non-negative accuracy lower bound for
explicit personal opinions and registered personal memories. Domain ownership is
enforced by ordinary scoped admission. Independent external grading is an explicit
assumption. Benchmark adapters keep gold labels outside the answer model and require
local operator-reviewed license notices; they neither download datasets nor import
arbitrary evaluation code.
