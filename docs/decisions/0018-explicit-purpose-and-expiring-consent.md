# 0018: Explicit purpose and expiring consent

Consent is an immutable operator enrollment of admitted canonical source IDs,
not an agent-supplied metadata grant. A bounded signed index attaches DPV purpose
and processing sets to existing memory without rewriting canonical bytes.
Retrieval intersects purpose with existing admission; expiry denies reads before
physical cleanup. Source-linked derivations preserve the restriction.

An owner explanation may inspect expired consent for a scoped source, through a
narrow internal owner-only context. Agents cannot activate this context. Raw
subject IDs become root-specific pseudonyms. Gateway purpose declarations must
match verified capability purposes; only trusted owner applications may select a
purpose without delegation.

Retention uses actual canonical erasure and G20 events. A configured external
subject-key vault permits the existing conditional crypto-erasure certificate.
Without that vault, cleanup reports pending certification after local purge.
No consent or key-destruction claim establishes remote erasure, truth, person
identity, legal compliance or retroactive encryption of backups.
