# UniMem typed trials and managed skill exports

Reuse promotion plans rather than creating a second release authority. Optional
typed-unit parameters change only new plans; the default legacy plan body is
unchanged. Publish a schedule before any typed occasion and refuse configuration
changes or early assignment. Serialize typed retries with a distinct lock:
canonical holdout I/O owns its own non-reentrant frontmatter flock.

A shared bundle-size factor precedes all inner skill arms. Eligibility uses a
fixed content order, never earlier treatment outcomes or the number of skills
actually shown. Excluded units get eligibility records, not withheld rows.

Keep candidate bodies in deletable blobs. Trace sources require authenticated
scope, lifetime and user/operator authority; successful agent output cannot
promote its own authority. Screens are explicitly heuristic. Only canonical
promotion certificates can publish, and a frozen post-publication monitoring
split enables decay retirement without reusing selected training data.

Agent Skills frontmatter contains only standard name/description fields. Signed
cards bind the rendered body and canonical candidate separately. A persistent
managed-export index prevents deleting the card from downgrading an export into
an unchecked legacy skill. Source erasure cascades through managed descendants
and deletes the local export. External copies remain outside this boundary.
