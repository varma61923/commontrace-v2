# UniMem complete-cohort RL export

Use authenticated trajectories bound to canonical trial occasions. Audit only
selected units, then require every canonical occasion to have a live, admitted
response. Selecting successful or visible responses alone would break both the
trial and the training labels. Fixed public nuisance predictions make the
advantage definition auditable without leaking a fitted private predictor.

Pair within full labels and observed tasks, never claim a same-instance
counterfactual. Keep sampled KL and replay priorities explicitly estimates and
heuristics. External Agent Lightning and grader mappings remain unverified
until pinned vendor fixtures are available.

Content shards inherit source scopes, have bounded source fan-out, and form a
qualified dependency graph through bounded indexes. Empty DPO datasets still
depend on their units. Erasure removes content, including authenticated capture
traces, while retaining signed metadata commitments. Batch provenance removal
after revoking all affected trace identities avoids both quadratic rewrites and
temporarily laundering a descendant through a removed edge.

HTTP streams preserve the authorization context through deferred iteration.
Canonical JSONL wire bytes, including connector mapping and newlines, define
the manifest digest. A failed midstream admission closes the chunked transfer.
