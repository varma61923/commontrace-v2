# UniMem portable evidence boundaries

Authenticate bytes and describe the assumptions behind a statistical claim
separately. A signature cannot establish that an agent executed a task or that
a recorded outcome is true.

Pooled random-effects intervals estimate a population effect under their model;
the combined e-value tests its stated joint directional null. These targets
must remain explicit. Independent organizations and their ownership groups are
established by operators, so creating more account identifiers cannot create
independent evidence.

Transparent recomputation discloses its input rows and is an audit backend.
A zkVM receipt must verify against a pinned guest image before its output can
claim private proof verification. Simulated attestation uses test keys and an
explicit simulation label. Production key release needs a configured platform
verifier and a trusted, logged measurement.

Standards mappings are pinned to versions or immutable source revisions. Vendor
formats without authoritative fixtures carry an unverified mapping label.
