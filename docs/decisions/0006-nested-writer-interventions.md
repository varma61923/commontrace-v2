# UniMem parent writer interventions

Keep parent assignments in the canonical typed-trial engine. Intercept reads
and memory assignment before inner randomization, preserving the original
record shape for every eligible assignment. Record masking as eligibility
metadata rather than inventing a memory control propensity. A context variable
keeps the default path inactive and rejects nested or mismatched occasions.

Use authenticated lineage actors and their descendants, with operator-pinned
role membership. Do not infer a writer for unsigned legacy data. Hazards bypass
the parent mask. Reliability stays an explicitly estimated prior; it does not
change source authority or issue a separate release certificate.

The seeded bias regression includes a direct writer contribution as well as a
memory contribution. Without it, a consistent nuisance predictor can conceal
the incorrect-propensity mutation through double robustness. The planted
design distinguishes the writer's marginal contrast from the conditional
memory effect and detects incorrectly pooled masked controls.
