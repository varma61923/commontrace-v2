# UniMem pooled estimates, ownership and reference privacy

Merge sufficient statistics within operator-established ownership groups before
meta-analysis. This follows the clean-room identity/stake trust boundary and
makes shard splitting invariant; self-reported organization names are not proof
of independence. Signatures attest provenance, not truthful or disjoint cohorts.

Use DerSimonian–Laird and modified Hartung–Knapp without silently changing the
requested estimator. A stress simulation exposed under-coverage with only eight
groups and extreme precision imbalance. Document it and warn below ten groups;
test the stated 24-owner regime, and retain model-based classification. The
pooled interval cannot authorize promotion and the combined e-value tests a
different, joint directional null.

Gaussian privacy is conditional on public counts and frozen public nuisances.
Otherwise a fitted nuisance change could alter all subsequent scores, violating
the claimed sensitivity. Suppress the exact private e-value, charge composition
before release, make budgets immutable and state the finite-precision sampler
limitation explicitly. These are reference privacy calculations, not an audited
production DP engine.

Validation: the full core Python 3.10 install passed 7,461 tests (347 optional
skips); the PostgreSQL 16 Hub suite passed 2,617 tests (46 optional skips).
Focused Python 3.12 pooling tests passed all 11; their statistical simulations
run below two seconds each. Ruff, configured strict mypy, Bandit `-ll`, both
OpenAPI checks, image import closure and local retrieval latency passed.
Graphify reports 350 modules, 288 reachability candidates and zero missing
endpoints. The module budget increased by exactly the four new core files.
An isolated mutation replacing the between-owner variance with zero reduces
24-owner coverage to 73/120 and fails the required 108/120 threshold. The same
simulation passes with the actual estimator. No mutation is retained in code.
