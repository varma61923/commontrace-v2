# UniMem visible dependency closure

Join the existing signed lineage with managed artifact source references and
explicit read instrumentation. Preserve canonical record formats. Resolve
qualified artifact references rather than inferring provenance from content.
Scope admission precedes traversal and every re-retrieval, including candidate
IDs supplied by a custom retriever.

Bound both the underlying scoped graph and its traversal. A truncated response
cannot claim completeness. Read payloads have fixed retry-stable retention
deadlines and an explicit physical prune operation; signed source commitments
are retained. Freezing remains an operator action through incident evidence.

Compute root concentration with fractional multi-root weights, grouping unknown
origins together. Treat this as structural diversity and expose its assumptions,
not a statistical independence certificate or a semantic-truth vote.
