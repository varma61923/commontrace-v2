# UniMem opt-in memory spans

Pin the external convention and validate names/types against an authored
fixture. Use `upsert_memory` for an API that can reinforce existing records.
Keep the standard single-record ID a string and put batch IDs under the vendor
namespace. Local operations use `INTERNAL` spans; no provider is invented.

Admit before constructing any observable attribute. Omit private query content
when a request contains a denied record. Keep content off by default, preserve
the disabled path's single cheap flag check, and suppress exception messages.
Optional exporter failures must not cause callers to retry committed writes.

Log canonical outcome arms in a separate vendor span. A task outcome is not a
memory operation, and dashboard rates are not a replacement causal estimator.
Created SDK spans are not network delivery receipts. Hosted dashboard mappings
remain unverified until deployment fixtures are available.

The accompanying skill-rendering correction normalizes leading and universal
newlines before signing a managed export's rendered-body commitment. It leaves
canonical candidate records and ordinary rendered skills unchanged.
