# sovereign-airgapped

Install this configuration with `commontrace pack install sovereign-airgapped --dest ./deployment` and run its offline reference demo with `commontrace pack demo sovereign-airgapped --seed 20261018`.

Configured roadmap features: G12, G14, G19, G21. Defaults and review rules are shipped in the versioned pack manifest. This is a starting configuration; review rules and integrations against the deployment policy before production. The demo uses seeded synthetic outcomes and makes no network calls. Its estimate is not evidence of field performance or certification.
